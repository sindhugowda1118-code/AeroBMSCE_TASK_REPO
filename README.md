# AeroBMSCE

A responsive, static website for the aerospace, aeromodelling and unmanned systems innovation club of BMS College of Engineering.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server. The site has no build step or third-party runtime dependencies.

## Pages

- `index.html` — team, mission, engineering divisions, aircraft, photo archive and crew application
- `journey.html` — competition teams and milestones
- `partners.html` — sponsorship and technical collaboration

## Crew applications

The recruitment form validates the required name, email and division fields, then prepares an email to `aerobmsce@bmsce.ac.in` in the visitor's default email application. The site does not store or submit applications; the applicant must review and send the email. A working form endpoint would require an application backend.

## Assets

All site imagery is stored in `images/`. There are no dependencies on the original downloaded capture, its preview service, analytics scripts or third-party assets.
